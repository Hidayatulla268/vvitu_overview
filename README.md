## ⚡ Highlights & Key Features

- **🌳 Interactive Hierarchical Tree**: Drill down through **Admin**, **Faculty**, **Student**, **HOD**, and **DEO** portals with expandable categories and sub-features.
- **🛡️ High-Contrast Modern Theme Engine**: Features Dark Obsidian and High-Contrast Light mode with customizable accent glows.
- **✨ Complete HOD Matrix**: Full visibility across all 6 HOD governance pillars (Academic Operations, Faculty Workload, Grade Approvals, Class Diary Compliance, Circulars, Feedback Analytics).
- **📱 Responsive & Standalone**: Pure zero-dependency client architecture powered by Bootstrap 5 and FontAwesome CDN.

## 🛠️ Usage & Deployment

To deploy this overview on **GitHub Pages**:
1. Go to repository **Settings** &rarr; **Pages**.
2. Under **Build and deployment** &rarr; **Branch**, select `main` and `/ (root)`.
3. Click **Save**. The interactive overview will be live at `https://hidayatulla268.github.io/vvitu_overview/`.
